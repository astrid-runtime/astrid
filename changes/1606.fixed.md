Layout-2 live upgrade no longer times out, mills the CPU, or rejects the AOS MCP plugin argv.

GetStatus is not a durable admin row. Chain-head lookup is metadata +
`audit:chain_heads`, not a session scan. Allowed `stat`/`exists`/`readdir`
are not signed FileRead rows. Identical host-audit events collapse with an
explicit `repeats=N` stamp and never block tokio. A missing `audit:chain_heads`
key is healed from metadata; head CAS is capped at 8 attempts. Runtime object
and KV read caches are on by default. `astrid mcp serve` accepts
`--workspace` / `--request-timeout` from AOS host plugins and attaches the
session to that project even when the process cwd is the runtime home.
