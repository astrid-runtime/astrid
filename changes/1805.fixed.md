AstridFS is now a hidden macOS-required FSKit container with no window, Dock
presence, or menu-bar UI. The lifecycle manager proves that macOS elected the
exact installed extension and validates the running container by executable
path, PID, codesign identity, and Astrid version. Installation accepts only the
co-installed companion staged beside the app after checking its Developer ID
identity and matching Astrid version. Certification binds signing to the
verified exact source SHA, exercises CLI status, dirty-state publication, mount
I/O, and unmount cleanup, and keeps the unmount sync-swallow residual recorded.
Local lifecycle tests prove refusal of unsigned and non-Apple-signed companions
without mutating an existing installation; successful update and rollback remain
exercised only with the Apple-issued certification-runner identity.
