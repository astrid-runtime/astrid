`astrid run` now loads its idle timeout from isolated pre-mount client
configuration instead of the broad runtime config. `ASTRID_CLIENT_CONFIG_PATH`
selects an explicit private file; the canonical AOS path is
`~/.aos/etc/astrid/client.toml`. The CLI override remains highest precedence,
the default remains 120 seconds, and values above one day are rejected.

Only messages correlated to the active run reset the idle deadline. This
includes session-bearing `agent.v1.stream.delta` payloads and excludes foreign
same-principal approval/control frames. Headless approval requests are never
answered, even when their publisher looks session-related, and never reset the
deadline. `--yes`, `--yolo`, and `--autonomous` are rejected before headless
execution. Timeout and disconnect sends are bounded, and the command still
returns exit code 53 at the CLI boundary.
Capsule HTTP timeout controls remain independent. Closes #1812 and #1816
