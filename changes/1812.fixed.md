`astrid run` now honors `timeouts.run_idle_secs` as its no-message idle
timeout and accepts `--idle-timeout-secs` for one invocation. The default
remains 120 seconds, valid active-run messages reset the timer, values above
one day are rejected, and timeout cleanup/disconnect runs before the command
returns the established exit code 53. Capsule HTTP timeout controls remain
independent. Closes #1812
