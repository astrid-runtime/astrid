issue_lease captures the caller's immutable UID before owner authorization and revalidates that exact binding, viewed-principal identity, fleet membership, and workspace-branch facts under the storage-mount mutation lock before create/bind/write/insert. A deletable caller cannot be represented as an absent UID; alias recycle after AgentDelete cannot republish. Drain uses the same lock after retirement, so admission either publishes before drain or publishes nothing. Failed endpoint or manifest cleanup keeps a revoked map entry, returns a diagnostic error, and AgentDelete preserves the identity alias until retry succeeds. Process-projection teardown revokes every remaining lease even when one resource cleanup fails, treating already-removed leases as done so retry can finish. Ordinary revoke uses the same helper.
