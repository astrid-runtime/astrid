Admin storage-mount requests bind AuthorizedPrincipal (trusted alias plus immutable PrincipalUid) at ingress before profile or capability lookup, then reconfirm that binding after the policy snapshot so alias replacement fails closed before lease admission. AdminRequestKind::requires_principal_identity replaces substring routing. Issue, Status, Sync, and Revoke consume one MountGrant; live leases retain the requester UID so alias equality is never ownership. Tests cannot dispatch mounts without that grant. Refs #1564
