# Security

- Bound process storage projection reuse and drain to the immutable acting UID,
  provider generation, durable owner, and complete typed target set.
  Tracking #1710.
- Kept user-private state excluded from process provider projections and
  retained revoked projection leases when cleanup fails; retained state blocks
  duplicate projection creation until cleanup succeeds. Tracking #1710.
- Rolled back every issued branch, owner-home, and Fleet-shared lease when a
  provider launch fails. On retained provider teardown, immediately fenced
  every exact published lease so authenticated callbacks and renewals fail
  stale-lease while provider handles and resources remained available for
  bounded retry. Tracking #1710.
- Reclaimed stale native process storage roots only through singleton-owned
  boot, using the same no-follow, mount-boundary-aware validation used for
  principal runtime scratch; lockless injected kernels preserve another live
  kernel's roots. Tracking #1710.
- Prepared Fleet shared storage, private HOME, parent tokens, and mount
  admission before allocating a provider-service UUID root. Tracking #1710.
