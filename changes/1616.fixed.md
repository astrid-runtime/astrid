The durable runtime tree can be explicitly admitted into the system-owned ASTVOL1 catalog. Runtime sockets, locks, readiness/token/PID sentinels, the volume itself, and bootstrap host binaries remain POSIX-owned; packed WASM is reconstructed from `bin/<hash>.wasm` catalog content. Boot admission is receipt-bound and runs before capsules load. Closes #1616
Storage-backed capsule installs now publish WASM to the system-owned `bin/<hash>.wasm` catalog, and native loads, authority checks, and Distro.lock verification use those bytes rather than a POSIX blob.
