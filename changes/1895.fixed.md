Automatically started MCP gateways now retire after the final host connection closes, using `gateway.idle_shutdown_secs` as the shutdown grace. Quiet connected sessions keep their gateway alive. `astrid start --ephemeral` allows host launchers to select connection-owned daemon lifetime without changing explicit persistent `astrid start` behavior.

Short startup probes no longer consume the daemon's existing startup handoff grace. After natural MCP shutdown, the stopped projection is packed and retired under the startup fence without stopping an operator-owned persistent daemon.

Shared gateways use their own process group, so cancellation of the host that initially started them does not disconnect other attached hosts.
