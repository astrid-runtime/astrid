Astrid durable staging-seal benchmark
======================================

Host
----
macOS 26.2 (25C56), arm64, Apple M2 Ultra

Comparison
----------
baseline:  d9af426f9988b43d85abb08409d7cc6087ef7e93
candidate: ca1f72d88eb81a6ed2c785005978b7f3c160fd66

The baseline worktree was detached at the exact candidate parent and differed
only by the ignored probe copied from the candidate. Each revision used its
own release target directory; no compiled benchmark binary was shared.

Command
-------
cargo test --release -p astrid-storage native_seal_group_scale_probe -- --ignored --nocapture

Workload
--------
For each concurrency point, every writer sealed 64 independent 4 KiB files.
Each seal flushed the content and returned only after its implementation's
durable intent boundary. Three fresh-directory samples were collected per
point. Tables in the canonical performance document report the median sample
for throughput and p95 latency independently.
